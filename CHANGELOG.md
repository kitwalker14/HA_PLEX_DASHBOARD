# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-04-21

### Added
- Initial HACS-installable release
- 4-column `sections` view dashboard
- Auto-discovered now-playing cards via `auto-entities` + `mini-media-player`
- Rich custom button-card per stream with poster, title, S/E or artist/album,
  user, state and progress bar
- Server overview: status, stream chips, bandwidth bar, action buttons
- Auto-discovered library count list
- Recently Added cards (Movies / TV / Music) with filter pill
- Coming Soon view (Radarr / Sonarr)
- Template sensors, scripts, helpers package
- Plex Dark theme
